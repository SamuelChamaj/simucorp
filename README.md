# SimuCorp Dashboard

Zjednodušená verzia – menej súborov, pripravená na GitHub.

## Štruktúra

```
app/page.tsx      ← celá aplikácia
lib/demoData.ts   ← demo dáta
app/globals.css
+ konfigurácia
```

## Spustenie

```bash
npm install
npm run dev
```

## GitHub

1. Vytvor nový repozitár na GitHube.
2. Nahraj tieto súbory (alebo celý priečinok).
3. Commit.
